## Intent

A 28-second cinematic promo for Aside Browser in a soft lavender, glassy style.
It is one continuous take inside a faithful recreation of the Aside UI (from the
supplied screenshot). The user types a task into the "Ask AI a task" bar, and the
agent sets up Sentry, deploys the app, triggers a production error, catches it
in Sentry, fixes it, runs the tests and redeploys. The film ends on a clean
success screen, then a "bring your own Claude or Codex subscription" beat, then
the tagline.

## Assets

- assets/fonts/ — Inter (UI), JetBrains Mono (code), Instrument Serif (title accents), all bundled locally.
- Brand glyphs for Sentry, GitHub, Notion, Discord, Claude, Facebook and Next.js are inlined from simple-icons; Gmail, Figma, Vercel, Codex and the Aside mark are drawn inline.
- assets/score.m4a — generated by `tools/make-score.mjs` (ambient pad plus UI sound marks), deterministic.

## Customizations

- Prompt typed verbatim: "Set up Sentry, deploy my app, trigger a production error, then fix anything broken."
- Agent spins up tabs for Sentry, the codebase (GitHub) and Vercel in the sidebar's Agent tabs group.
- Secure autofill from the Aside vault on the Sentry sign-in, Sentry project creation, DSN kept masked.
- Code diffs, env vars, deploy progress, the error, the Sentry catch, the fix diff, passing tests and the redeploy.
- Final success screen: "Production healthy", "Sentry connected".
- Sign in with your own Claude or Codex subscription, with no extra AI bill.
- End line: "Aside Browser. The AI browser for real work."

## Notes

- 1:1 recreation of the Aside chrome: traffic lights, Personal switcher, Bookmarks, Tabs, Agent tabs, the selected New Tab pill, the Ask AI bar with Tab-to-switch, the Search/Ask AI toggle, Local, Guard, the model picker, and Recent tasks.
- aside.com is unreachable from the build sandbox, so no site capture ran; the UI is rebuilt from the screenshot.
- Render requested by the user up front (local preview + final MP4).
